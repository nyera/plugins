لوحة تحكم متقدمة لإدارة متجر WooCommerce بتصميم عربي RTL

== Description ==

إضافة لوحة تحكم مخصصة لمتجر WooCommerce بتصميم عربي كامل تتضمن:

* لوحة رئيسية بإحصائيات المبيعات والطلبات والعملاء
* مدير عمليات شامل
* إدارة الطلبات والمنتجات والعملاء
* نظام القسائم والتخفيضات
* تحليلات المنتجات والإيرادات
* إدارة المدفوعات والشحن
* إدارة المستخدمين والصلاحيات
* إعدادات المتجر والمظهر
* مكتبة الوسائط
* صفحة الدعم الفني
* وضع ليلي (Dark Mode)
* تصميم متجاوب (Responsive)

== Installation ==

1. ارفع مجلد `yamamah-dashboard` إلى `/wp-content/plugins/`
2. فعّل الإضافة من قائمة "الإضافات" في ووردبريس
3. تأكد من تثبيت وتفعيل WooCommerce
4. ستظهر قائمة "اليمامة" في الشريط الجانبي لوحة تحكم ووردبريس
